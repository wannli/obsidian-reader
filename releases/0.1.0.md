# Reader 0.1.0

## Features

Reader is a Markdown-first Obsidian plugin for saving articles, following RSS and Atom feeds, reading in focused queues, highlighting passages inline, linking highlights to vault notes, and assigning topics. It supports desktop and mobile, with optional pagination for Android e-ink devices.

## Installation

Download `main.js`, `manifest.json`, and `styles.css` from the release and place them in `<vault>/.obsidian/plugins/obsidian-reader/`. Enable Reader in Obsidian's Community plugins settings. BRAT users can install `wannli/obsidian-reader`.

## Limitations

This is the first standalone release under the `obsidian-reader` plugin ID. It installs separately and does not import settings, hotkeys, or workspace state from another plugin. Device-specific native behavior should be verified on the target device.

## Verification

This is the first release of the clean standalone repository. Automated type, unit, tooling, build, and browser checks are required before publication. Native iOS, e-ink hardware, and cross-device sync checks are not claimed by browser or synthetic tests.
