What this does—and does not—settle

  • No reverse link: a clipping points to the article. Reader would discover cards by type and inspect their origins; the actual scan/index mechanism is not designed here.
  • Independent files: renaming a card or adding thoughts never changes its source article. Deleting either file never automatically deletes the other.
  • Location is not selection: origin locates a paragraph, but does not say which words were originally selected.
  • Proposed matching: this demo uses the first blockquote to find the kept words in that paragraph. Editing it can make matching and duplicate detection uncertain. It does not save a hidden extra copy.
  • Unresolved: exact selection anchors, repeated text, multiple cards from one paragraph, and what happens after someone rewrites the quotation. The demo stops rather than inventing an answer.
  • No source reference? this demo blocks precise capture. We still need to choose between a less precise article-only link and a different locator. It does not silently add a block ID.
  • Not simulated: dirty editors, Fileclass setup, real link rewriting, concurrent writes or Sync. No new production schema is approved by this mockup.
