01 / Bring it into the vault

Save now.
Acquire when available.

A saved URL does not depend on a successful network request.

host/ingestion.ts · content/
  • Native Add URL: creates an offline note immediately; duplicate URLs open the existing article.
  • RSS & Atom: save feed text first; request missing full text on opening or moving to Inbox/Later, subject to ownership guards.
  • Bounded refresh: consider the latest 20 before deduplication and age filtering, initially, manually, and every four active hours.
  • Recoverable failure: retain available text and the URL, show the error, and offer Retry without overriding protection.

No backlog cursor or deleted-URL history. Bursts over 20 can be missed; deleted entries still in the window can return.

04 / Safety at the boundaries

Refuse a risky write. Keep the note.

The important changes are not all visible UI. These safeguards close data-loss and stale-action races.

A highlight save, explained

Illustrative flow only. These controls do not touch a vault.

01 / SELECTMap the displayed words

Resolve the range against the exact rendered source, not a newer unseen body.

02 / RETAINPromote before annotation

A disposable Stream note moves to Inbox before its annotation can be saved.

03 / RECHECKValidate at the write boundary

Confirm current identity, raw bytes, editor safety and operation lifetime.

04 / OUTCOMESave ordinary Markdown

Apply the precise source edit and preserve the original browsing context.

Unchanged source → the guarded edit may proceed. A position-only save does not remount the article.
A / AUTHORSHIP

No guessed ownership

Acquisition replaces only an empty body or an exactly re-proven current feed excerpt, with a matching raw revision. Dirty preview buffers, source editors and ambiguous selections are protected.

B / RETENTION

Protect before trash

Authored annotations and vault links—including unknown YAML properties—protect Stream items. Reader source/state fields do not count as annotations. Final trash checks revalidate after the final read.

C / UNTRUSTED INPUT

Bound and sanitize

HTML/XML byte, node and depth budgets; hidden content removed; executable fence labels stripped. Default Dataview inline expressions and Templater delimiters fail capture, including in titles.

Other fixes that matter when timing gets awkward

Folder rename/delete events update descendant paths and revoke capture receipts. File/folder and case collisions never authorize overwrite. Joined subscription callers cancel independently. Late modal results cannot hijack another article. Deletion uses vault-local recoverable trash. A timed-out uncancellable network request keeps its slot until the host settles it.

A new untitled manual capture can receive its extracted-title filename only while its session-only receipt remains valid. Explicit titles, duplicate captures, user moves/renames, and restart prevent automatic retitling. No ownership stamp is persisted.

Not an atomic cross-device transaction. Obsidian unload is best effort; already-started native I/O cannot be rolled back. Reader also cannot sandbox arbitrary third-party Markdown processors.
