# Hosted-highlight manual acceptance

Status: **partial human confirmation; full matrix pending**. Grouped-pill, empty-search and top-topics build `66bf883b…` was installed and verified loaded; Wannes reported that it works. This does not certify every desktop case, physical touch/e-ink devices or Sync, and automated checks are not native acceptance. Use only the owned, backed-up E2E vault. The [contract](hosted-highlights.md) defines expected behavior, not permission to erase a failing example.

## Before testing

- Record artifact hash/worktree, Obsidian/Fileclass/Inline versions and device/model. Pin the registered E2E vault ID, never the active/default vault.
- Verify marker and current backup receipt. Preserve settings, definitions/templates, capture setup, Welcome/Daily and Sync boundaries. No Hot Reload/watchers/instrumentation in Sync; do not reset files Wannes may have edited.
- Agents have no native access under the standing hold or a closed lease. Wannes can test manually; installation/reset permission is not unlimited native-input authority.
- Use actual public topic/concept/person membership plus an untyped decoy. Exercise a real registered multi-class note/required-field schema when available; do not fabricate their syntax from assumptions.

## Cases

1. **One remembered host.** Select in the single-default article: no picker. Check native reference/paragraph ID and the destination quote. Add another checked note while keeping the first; both copies remain. Default changes do not silently reassign older passages.
2. **No remembered host.** Select in the unassigned article. Reader opens an empty full-width search field, not the selected quotation, with quiet native-style suggestion rows, clearly separated title/type metadata and compact creation options, not grey button slabs or an existing/create wizard. Cancel: no annotation/quote. Choose a typed note and apply; it becomes a remembered destination.
3. **Multiselect.** Check several notes, change query/class filter and return. Checks persist; only title/type/icon is prominent, paths disambiguate duplicates. Apply once: one source annotation, several copies. Related notes permits zero selections and edits defaults separately.
4. **Typed-only selection.** Search title/alias/fuzzy candidates and type filters. Exclude the untyped decoy; show a real multi-class member under every registered membership. All types never means All files. Verify write failure retains the staged choices for explicit retry.
5. **Explicit creation.** Create one typed note alongside checked existing notes. Public required-field completion still works; the highlight callback saves before completion. Check birth origin from the actual source paragraph. Cancel/navigate during completion: known created note/source work remains, never deleted or falsely reported as fully filed.
6. **Related-note creation.** In Related notes, creation durably links only the new note before completion; other checks remain staged until final Apply. Cancel leaves that known link/note. Failure/reopened picker retains the draft without another automatic creation or write.
7. **Formatting and URLs.** Select partial publisher labels and cross plain/bold/link/emphasis boundaries. Only selected words are highlighted/quoted, with balanced Markdown and original URLs. Existing highlights nested in native note-link labels remain quotable without turning unhighlighted vault links into new selection surfaces.
8. **Repeated words.** Select the second occurrence. Only it changes, including after reload. No reference label, icon metadata or paragraph marker becomes selected prose, tap words, quote text or bookmark text.
9. **Shared paragraph/publisher link.** Create two separate highlights with different hosts in one paragraph and inside one publisher link. Preserve separate ordered reference groups and one native paragraph ID, including CRLF. Remove one association/group without changing the sibling, publisher label/URL or anchor.
10. **Node-only conversion.** Explicitly convert a phrase through a single-choice picker: ordinary wikilink/exact alias, no highlight/redundant references or quotation of the node name. Preserve existing origins (including empty/null); new notes alone get origin. Publisher-link conflicts refuse safely. Existing filed snapshots remain.
11. **Highlight destination editing.** Click highlight A once to select it and again to open its notes picker. Clicking highlight B instead selects B. The toolbar's **Add highlight to notes…** opens the same picker. Unchecking a destination removes only its matching unchanged quotation; cancelled drafts leave notes unchanged.
12. **Reference navigation/icons.** All references for one highlight share one native-sized pill containing only their Fileclass icons/names, with no generic marker. Each destination remains independently clickable and opens its note, including while a highlight is selected. In a dense paragraph the group preserves ordinary line spacing; long labels must not overflow mobile widths. Modifier-click opens another pane. All typed-note links, including ordinary prose links, show the public Fileclass-resolved icon; untyped/web links remain plain. Icon paint/provider loss must not hide labels or contaminate prose.
13. **Secondary article selection.** Choose from article can explicitly target a highlight or typed inline node. A multi-host target asks which destination; a specific reference uses only that node. Cancel/Done clears transient sending; an untyped node cannot become a host.
14. **Grouping, dates and retry.** New quotes use a native path-identified article H3 under Highlights, each with a paragraph citation/local date. Reuse the right heading despite title collisions; preserve other sections/flat legacy quotes. Same quote/citation retry adds nothing and preserves its original date/undated form; different excerpts remain distinct.
15. **Explicit removal.** Uncheck one highlight destination: remove its source association and unique exact saved quote. Zero checked destinations removes its marks/references, not words/formatting/wiki/publisher URLs/shared ID. Missing, edited, commented-out or ambiguous copies must block before source mutation. Commented section headings never become filing destinations. Keep other quotes, comments, origin and possibly authored empty headings.
16. **Promotion and protected writes.** Feed collection retains in Later before annotation; inspect physical path/status/bookmark and postmove source heading/citation/origin. Dirty/uncertain/source-mode targets refuse; clean reading mode works. Do not alter native link-update preferences to pass.
17. **Partial progress.** Simulate an append/removal failure after source save: report saved source and each verified completed target operation. For initial native/tap collection into existing A and newly created B, fail B after A saves; Retry note updates must write only B, preserve its new-note origin authority, and leave A/date/source bytes unchanged. Explicit retry neither duplicates copies nor repeats completed removals/guesses absent copies. Cancellation/navigation drains dispatched writes without silently undoing prior progress.
18. **Snapshot independence.** Edit/delete source text, change Related notes, convert, use explicitly article-only removal or ordinary source Undo. Stored copies remain; no automatic synchronization/deletion or Feed demotion. Only case 15 authorizes matching-copy removal; no misleading source-only Undo promises target restoration.
19. **Lifecycle and reading.** Cancel/navigate/close/reconfigure during pick/create/write; no stale article write, duplicate callback or stuck uncooperative completion. Check actual desktop/mobile/e-ink tap/drag handles, Sentence/Paragraph, scroll/paging, Done/Escape, Undo, images, filters, dog-ear and resume.
20. **Restart/Sync.** Open ordinary Markdown and Reader after restart; repeat on authorized devices. Record interrupted/conflicting writes and actual device models/latencies separately. A Synced indicator alone proves neither conflict handling nor physical-device acceptance.
21. **Article topics at the top.** Existing article topics appear in the top reading header using the same compact pill and public Fileclass icons, without a generic marker or new metadata. Related notes changes refresh this display. Long labels stay within mobile widths; metadata never enters selected prose, quotes or bookmarks. Verify scroll/paged header geometry.
22. **Legacy compatibility.** Plain highlights and ordinary linked highlights stay readable without rewrites or new destination copies. A legacy linked phrase alone does not authorize deletion of a similar quotation. No startup migration, backfill or personal-vault mutation.

## Record

For each case record pass/fail, device, source/target paths, before/after Markdown and error. Keep backups/screenshots/instrumentation outside Sync. Several destination notes for one highlight are in scope; batch collection of several source highlights, last-used destination, node-first collection and evidence roles remain deferred.
