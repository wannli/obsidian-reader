# Triage labels

Map canonical skill roles to these GitHub label names.

| Canonical role  | GitHub label    | Meaning                                    |
| --------------- | --------------- | ------------------------------------------ |
| needs-triage    | needs-triage    | Maintainer evaluation needed               |
| needs-info      | needs-info      | Waiting for reporter information           |
| ready-for-agent | ready-for-agent | Fully specified for independent agent work |
| ready-for-human | ready-for-human | Requires human implementation              |
| wontfix         | wontfix         | Will not be actioned                       |

Use the mapped label whenever a skill mentions a canonical role.
A readiness label alone does not prove a ticket is available:
also check current status, ownership, blockers, and active work.
